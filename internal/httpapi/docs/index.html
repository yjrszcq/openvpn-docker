API Reference

Each operation lists its complete request, responses, and error statuses. All requests except /healthz require a Bearer API key.

Set OVPN_API_LISTEN to 127.0.0.1:<unused-port> for host-only access, or 0.0.0.0:<unused-port> for all IPv4 interfaces. Use an unused host port from 1 through 65535; the host-networked service needs no ports mapping. An empty value disables the API.

Set OVPN_API_CORS_ORIGINS to comma-separated domains or IP addresses, optionally with ports and without a scheme, for example vpn-admin.example.com,192.0.2.10:3000. Use * alone to allow any HTTP(S) origin, or leave it empty to disable CORS.
