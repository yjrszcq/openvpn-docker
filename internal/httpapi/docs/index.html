API Reference

Each operation lists its complete request, responses, and error statuses. All requests except /healthz require a Bearer API key.

VariableDefaultAccepted valuesDescription
OVPN_API_LISTENempty127.0.0.1:<unused-port>
0.0.0.0:<unused-port>		Uses any unused host port from 1 through 65535. Host networking needs no ports mapping. An empty value disables the API.
OVPN_API_CORS_ORIGINSemptydomain-or-IP[:port][,...]
*		Omit the scheme. Commas allow multiple values; for example, vpn-admin.example.com,192.0.2.10:3000. Use * alone for any HTTP(S) origin. An empty value disables CORS.

API key commands

CommandDescription

docker exec openvpn ovpn api key create frontend-production --output /etc/openvpn/frontend.keyCreates a key and writes it to a new mode-0600 file inside the container.
docker exec openvpn ovpn api key listLists key metadata without revealing secrets.
docker exec openvpn ovpn api key delete frontend-production --yesDeletes the named key and invalidates it immediately.
